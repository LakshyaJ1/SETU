## Prior-art positioning summary

| SETU mechanism | Closest prior art | What is new here |
|---|---|---|
| **SVO** spectral virtual odometer | [R46][R47][R48] — chassis-vibration speed tracking, never used in a navigation filter | Fusion into a learned invariant filter on a phone, with learned family disambiguation from gear-change discontinuities and heteroscedastic σ |
| **CTS** coordinated-turn speedometer | textbook kinematics; used implicitly in [R3][R31] | Used as an explicit absolute-speed *measurement* that calibrates the odometer scale; **lean-corrected form for two-wheelers** |
| **CSA** curvature-signature alignment | [R37][R38] — heading/length sequence matching **with known speed** | **Scale-free**: arc-length scale solved jointly with offset and path; differentiable (soft-DTW) so the velocity network is trained to be map-consistent |
| **PID** privileged distillation | [R18][R19] — WhONet consumes CAN wheel speeds at inference | Wheel speeds used as *training-only* privileged supervision for a phone-only student, plus a virtual-CAN multi-task head |
| **IAF** invariant adaptive fusion | [R3][R4][R20][R21] | Combination of learned σ (TLIO) + learned Q (A-KIT) + RI-EKF (AI-IMU) inside an RB-PF over the road graph, trained end-to-end |
| **EFA** field anchors | [R41][R43][R44][R45] — surveyed magnetic maps | Crowdsourced on-device anchor building as a by-product of ordinary driving, with retrospective smoothing between GNSS-good endpoints |
